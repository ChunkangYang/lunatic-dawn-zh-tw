# 俠客遊：前途道標 — 繁體中文補丁（非官方）

《Lunatic Dawn: Passage of the Book》（ルナティックドーン 前途への道標，ARTDINK，Steam 版 App 335420）的非官方繁體中文化補丁。
遊戲視窗標題沿用 1999 年台灣中文版的名稱「俠客遊：前途道標」；**本專案與 ARTDINK、Valve、第三波及任何原發行商皆無關**。

> **狀態：v0.2.0（可玩的測試版）**。遊戲文字與主要介面圖已中文化，仍有未處理與未驗證的部分，見「已知限制」。

## 需求

- Steam 正版《ルナティックドーン 前途への道標》，`Ld95.exe` 版本 **1.0.3.16**（補丁會用 SHA-256 檢查，版本不符會拒絕套用）
- Windows 10／11
- [Python 3.8+](https://www.python.org/downloads/)（只用標準函式庫）
- **Windows 系統地區（非 Unicode 程式的語言）必須是「中文（台灣）」**，原因見下

## 安裝

1. 到 [Releases](../../releases) 下載 `LunaticDawn-zh-TW-0.2.0-tw.zip` 並解壓縮（或直接 clone 本 repo）。
2. 設定系統地區為中文（台灣）並**重新開機**：
   設定 → 時間與語言 → 語言與區域 → 管理語言設定 → 變更系統地區設定 → 「中文（繁體，台灣）」。
   不要勾「Beta：使用 Unicode UTF-8」。**不要用 Locale Emulator**。
3. 在解壓縮資料夾執行：
   ```
   python apply_patch.py
   ```
   會自動找 Steam 的遊戲資料夾（也可用 `--game "路徑"` 指定），先把被修改的檔案備份成 `*.orig`，再套用補丁並檢查雜湊。
4. 從 Steam 啟動遊戲，**請新建世界**（舊存檔內的名稱仍是日文碼，在繁中系統會亂碼）。

| 指令 | 作用 |
|---|---|
| `python apply_patch.py --check` | 只檢查能否套用，不改檔 |
| `python apply_patch.py --restore` | 還原成日文原版（用安裝時留下的 `*.orig`） |

Steam「驗證遊戲檔案完整性」會把檔案還原成日文版，重新執行 `apply_patch.py` 即可。

### 為什麼系統地區要設成中文（台灣）？
遊戲是 1997 年的 ANSI 程式，字串用「系統碼頁」解讀。本補丁把文字寫成 Big5（CP950），所以系統碼頁必須是 950。
補丁同時修正了遊戲自己建立字型時寫死「日文字元集」的 4 個位置，否則狀態視窗的名字會變成亂碼。

## 補丁改了什麼

- **遊戲文字（exe 內）**：選單、對話框、系統訊息、道具／武器／防具名稱與說明、怪物名稱、地名人名稱號、NPC 台詞與委託任務
- **介面圖 49 檔**：狀態視窗各頁、按鈕、角色符號對話框、旗幟國名、地圖視窗上的城鎮名與街道名
- **版面調整**：選單列間距、快速鍵對齊、按鈕文字置中、視窗標題

## 已知限制

- **未處理**：地下城資料 `DUNG*.DAT`（疑似壓縮，是否含事件文字未確認）、結局與標題畫面的圖內文字、牌面圖、遊戲附的手冊 HTML 與 `ld95.chm`（仍是日文）。
- **未完整驗證**：戰鬥訊息、部分接在名稱後面的拼接句（語序）、「%D先生」的性別用語、部分特殊字尾字元的道具名。
- 已知小瑕疵：城市「傳聞」視窗標題尾端可能出現 `-?-`（未能穩定重現）。
- 翻譯由 AI 輔助完成並經實機抽查，**未逐條人工校對**。歡迎開 Issue 回報（請附截圖與畫面位置）。
- 完整清單見 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。
