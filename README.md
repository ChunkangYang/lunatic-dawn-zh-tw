# 俠客遊：前途道標 — 繁體中文補丁（非官方）

對象：《Lunatic Dawn: Passage of the Book》（ルナティックドーン 前途への道標，ARTDINK，Steam App 335420）。
視窗標題沿用 1999 年台灣中文版名稱「俠客遊：前途道標」。**本專案與 ARTDINK、Valve、第三波及任何原發行商無關。**

狀態：v0.2.2 測試版。已知限制見 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。

## 適用條件

| 項目 | 規格 |
|---|---|
| 遊戲 | Steam 正版，`Ld95.exe` 版本 1.0.3.16（SHA-256 不符則拒絕套用） |
| 系統 | Windows 10／11，系統地區（非 Unicode 程式語言）＝中文（台灣） |
| 執行環境 | exe 版：無；Python 版：Python 3.8+ |

## 安裝

1. 自 [Releases](../../releases) 下載其一並解壓縮：
   - exe 版：`LunaticDawn-zh-TW-0.2.2-tw-exe.zip`
   - Python 版：`LunaticDawn-zh-TW-0.2.2-tw.zip`
2. 執行：
   - exe 版：雙擊 `LunaticDawn-zh-TW-patcher.exe`
   - Python 版：`python apply_patch.py`
3. 自 Steam 啟動遊戲。**須新建世界**（舊存檔名稱為日文碼，會亂碼）。

### 參數

| 參數 | 作用 |
|---|---|
| `--check` | 僅檢查，不改檔 |
| `--restore` | 以 `*.orig` 還原為日文原版 |
| `--game "路徑"` | 指定遊戲資料夾（預設自動尋找 Steam 路徑） |

### 注意事項

- 備份：被修改的檔案於**原目錄**備份為「原檔名＋`.orig`」（例：`Ld95.exe.orig`）。**勿刪除**，`--restore` 需要。
- 套用後**勿使用 Steam「驗證遊戲檔案完整性」**。Steam 會還原為日文版；誤用時重新執行補丁。
- 遊戲更新後版本不符時，補丁拒絕套用。
- exe 版未經程式碼簽章，SmartScreen 可能警告、防毒軟體可能誤報（補丁會改寫 `Ld95.exe`）。遭攔截時改用 Python 版。

### 系統地區須為中文（台灣）的原因

遊戲為 ANSI 程式，依系統碼頁解讀字串。補丁以 Big5（CP950）寫入文字，故系統碼頁須為 950。
補丁並修正遊戲建立字型時寫死日文字元集（4 處），否則狀態視窗名字會亂碼。

## 補丁內容

- exe 內文字：選單、對話框、系統訊息、道具／武器／防具、怪物、地名人名稱號、NPC 台詞、委託任務。
- 說明檔（工具列「?」）：76 頁說明、目錄、索引。
- 介面圖 49 檔：狀態視窗、按鈕、角色符號對話框、旗幟國名、地圖城鎮名與街道名。
- 版面：選單列間距、快速鍵對齊、按鈕文字置中、視窗標題。
